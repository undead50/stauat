# STA Community Nursing — static preview

A static, view-only snapshot of the site for the client to click through.
This is **not** the live WordPress site — it's a plain HTML/CSS/JS copy of
every page as it looked when exported, with no database or server behind it.

## What works

- Every page, all navigation (desktop mega-menu and mobile drawer), all
  images, all styling and animations.

## What doesn't work (no backend to talk to)

- The contact/enquiry/"Start your journey" forms, the newsletter signup,
  and the chat widget don't submit anywhere.
- The site search box.
- Anything added or changed on the real site after this export was taken —
  this is a frozen snapshot, not a live mirror.

## Hosting it on GitHub Pages

1. Push this folder's contents to a GitHub repo (as the repo root, or to a
   `/docs` folder — either works, just set the matching option below).
2. In the repo's **Settings → Pages**, set the source to the branch/folder
   you pushed to, and save.
3. GitHub will publish it at `https://<your-username>.github.io/<repo-name>/`.
   Every link in these pages is a relative path, so it works correctly at
   that subpath (as opposed to the domain root) without any further changes.
4. `.nojekyll` is already included — GitHub Pages runs a Jekyll build by
   default, which would otherwise silently drop files/folders starting with
   `.` or `_` (this theme has a `wp-content/themes/stacare/dist/.vite/`
   folder), so leave that file in place.

A **project** Pages site (`username.github.io/repo-name/`) is public to
anyone with the link, even on a free GitHub plan — there's no built-in way
to password-protect it. If the client preview needs to stay private, that
needs GitHub Pro/Team, or a different static host.

## Refreshing it later

This folder was generated by crawling the running local site (every URL in
its own XML sitemap, plus every asset each page references) and rewriting
every internal link to a relative path. If the real site changes and you
want an updated snapshot, ask Claude to re-run the export.
